How it decides

These are the four rules the tokens and components follow.

  • Fact first

    Each label names the outcome, and each consequence is stated once. "Retry transaction", not "Proceed".

  • Dense but legible

    38px rows, tabular numbers and mono IDs. Tables paginate after 10 rows, with the same footer everywhere.

  • Three paths per page

    Every page is designed for the happy path, the error path and the edge case. Errors say what happened, that nothing changed, and what to do next.

  • Reasons on record

    Risky actions need a reason code and leave an audit trail. Disabled buttons say why, even on touch screens.
